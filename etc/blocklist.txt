# Open-Domain blocklist — one rule per line, "#" starts a comment.
#
#   ip     203.0.113.10       block one address
#   cidr   203.0.113.0/24     block one block
#   allow  203.0.113.5        an exception; always beats a block
#
# Decisions are made on the RESULTING ADDRESS, never on the name. So blocking
# 203.0.113.10 also closes 203-0-113-10, cb00710a (hex), anything.203.0.113.10 and
# 0203.0.113.010 in one go — no spelling can slip past.
#
# After editing this file:  systemctl kill -s HUP open-domain
# (or wait at most 15 seconds; the mtime change is noticed on its own)
#
# Every rule is recorded in git history — timestamped evidence that an abuse report
# was acted on, which cannot be manufactured after the fact.

# RFC 5737 documentation address — used as the example on the website, so it must
# never actually be blocked or the documented example stops working for people.
