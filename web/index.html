// formats

Four ways to write an IP.

Pick whichever fits. Dotted for humans, dashed for TLS wildcards, hex when you're feeling fancy, and full IPv6 support.

Dotted ·default

The natural way. An optional prefix in front is ignored.
app.10.0.0.1.a-i.sh → 10.0.0.1

Dashed ·for TLS

One label, so a single *.a-i.sh cert covers it.
192-168-1-20.a-i.sh → 192.168.1.20

Hex

Eight hex digits pack a full IPv4 into one short label.
0a000001.a-i.sh → 10.0.0.1

IPv6

Swap colons for dashes; -- stands in for ::.
2001-db8--1.a-i.sh → 2001:db8::1

// how it works

No database. That's the trick.

Open-Domain runs an authoritative DNS server and nothing else. It never stores a single record.

You query

A resolver asks Open-Domain for 1.2.3.4.a-i.sh.

It reads the name

A tiny regex pulls the IP straight out of the hostname — no lookup.

It answers

Returns 1.2.3.4. Your traffic then goes direct to that IP.

Stateless = featherweight. The answer is computed, never stored — which is exactly why it can be free forever.

// faq

Questions.

Is it really free?

Yes. The answer is computed straight from the hostname — there's no database and no per-record cost, so serving it is almost free. It's open-source (MIT) and community-funded, and the whole server is self-hostable, so it isn't riding on one company's goodwill. Free for dev, testing, and agent use.

Can I use it in production?

For side projects, demos, sandboxes, and agents — go for it. For anything critical, run it on a domain you own: a public service can rate-limit or go down, and you don't want your uptime tied to ours.

Who runs it — and will it stay up?

Open-Domain is open-source, MIT-licensed public infrastructure for the agent ecosystem, maintained in the open and community-funded via GitHub Sponsors. Because the entire DNS server is a tiny zero-dependency Node app, you're never locked in: if the public endpoint ever rate-limits or goes away, you can self-host the exact same thing on a domain you own in minutes.

How do I get HTTPS?

Use the dashed form (192-168-1-20.a-i.sh). Because it's a single label, one *.a-i.sh Let's Encrypt certificate covers it — no per-IP cert dance.

Does it support IPv6?

Yes. Swap the colons for dashes, and use a double dash for :: — so 2001-db8--1.a-i.sh resolves to 2001:db8::1.

Do you log my IP addresses?

Open-Domain answers a DNS query and nothing more, but every resolver between you and it can log the names it sees. Treat hostnames as public — never put a secret, token, or private detail in one.

Is it open source?

Yes — the whole DNS server is a tiny zero-dependency Node app. Read it, fork it, or self-host it on your own domain. GitHub →
